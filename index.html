Menstrual Cycle Length Analysis

Exploratory analysis of a public fertility dataset from the Marquette NFP study, done before any modelling. The goal is to know what a prediction model can honestly learn.

What I found: cycles from the same woman are not independent, so a model must be tested on women it has not seen. Some columns are calculated from the same cycle and would leak the answer. About 48% of the variation in cycle length is a stable difference between women.

  • Python
  • pandas
  • matplotlib
  • Google Colab
Open the Colab notebook
1,653cycles from 159 women after removing duplicates
